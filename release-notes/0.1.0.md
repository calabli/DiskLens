DiskLens 的第一个预览版：一个原生 macOS 磁盘空间工具，告诉你空间在哪、是谁在什么时候占掉的、哪些可以放心删。

## 功能

- **快速扫描**：多线程批量读取目录，160 万个文件的主文件夹约 7.5 秒扫完；再次打开时只更新变过的文件夹。
- **方块图和环形图**：边扫边长，可以逐层放大，和左侧的文件夹列表联动。
- **清理建议**：48 条规则加上「不活跃项目」「已卸载应用残留」两种判断，每条都写明删了会怎样。规则会在线更新，并且带签名校验。
- **开发环境**：Xcode 与模拟器、Docker、Homebrew、Java、Go 占了多少、哪些还在用，能用工具自己的命令删除就用它的命令。
- **文件名搜索**、**大文件**、**重复文件**（能识别 APFS 克隆）、**应用卸载**（连同残留数据）。
- **空间时间线**：后台记录每个应用写了多少、哪些文件夹在增长（可在设置里关闭）。
- **清理记录**：每次清理都有记录，清空废纸篓之前可以放回原处。
- **存储详情**和**菜单栏**剩余空间提醒。

## 系统要求

macOS 14 Sonoma 及以上，Apple 芯片和 Intel 机型都能用。

## 安装

1. 下载 `DiskLens-0.1.0.zip`，解压后把 DiskLens 拖到「应用程序」文件夹。
2. 这个预览版还没有经过苹果公证，第一次打开时 macOS 会拦住。在「应用程序」里**按住 Control 点按 DiskLens，选「打开」**，再在弹出的提示里点「打开」。如果没有「打开」选项，到「系统设置 › 隐私与安全性」，在页面下方点「仍要打开」。
3. 首次启动时按引导开启「完全磁盘访问权限」，否则邮件、信息、废纸篓等位置扫描不到，结果会偏小。

## 隐私

所有分析都在本机完成，不上传文件名，不收集使用数据，也不需要账号。唯一的网络请求是每天最多一次下载公开的清理规则，可以在设置里关闭。删除的东西只会移到废纸篓。

## 已知问题

- 未经公证，首次打开需要按上面的步骤手动允许。
- 每次更新到新版本后，可能需要重新开启完全磁盘访问权限。
