DiskLens 0.2.4 预览版：检查更新更稳定。

## 改动

- **检查更新不再受 GitHub 访问次数限制**：发布列表现在也放在 GitHub Pages 上，DiskLens 先从那里读取，读不到再退回 GitHub 接口。以前在公司、学校这类很多人共用网络的地方，可能因为 GitHub 每小时 60 次的限制而查不到更新。

## 升级

已经装了 0.2.x：在 DiskLens 菜单里选「检查更新…」，点「下载并安装」即可。

还在用 0.1.0：需要手动下载 `DiskLens-0.2.4.zip`，解压后替换「应用程序」里的 DiskLens。

## 系统要求

macOS 14 Sonoma 及以上，Apple 芯片和 Intel 机型都能用。

## 首次安装

1. 下载 `DiskLens-0.2.4.zip`，解压后把 DiskLens 拖到「应用程序」文件夹。
2. 这个预览版还没有经过苹果公证，第一次打开时 macOS 会拦住。在「应用程序」里**按住 Control 点按 DiskLens，选「打开」**，再在弹出的提示里点「打开」。
3. 首次启动时按引导开启「完全磁盘访问权限」。

## 已知问题

- 未经公证，首次打开需要手动允许。
- 每次更新到新版本后，可能需要重新开启完全磁盘访问权限。
