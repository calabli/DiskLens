DiskLens 0.2.0 预览版：开始支持应用内检查和安装更新。

## 新功能

- **检查更新**：应用菜单里的「检查更新…」，以及每天最多一次的自动检查。可以在「设置 › 软件更新」里关闭自动检查，或选择是否接收预览版。
- **安装更新**：发现新版本时显示发布说明，一键下载并安装。安装包会先用内置的密钥校验签名，并确认版本号无误，才会替换当前的 DiskLens；旧版本移到废纸篓，安装后自动重新打开。
- **关于 DiskLens**：显示版本号、构建号、编译时间和对应的代码版本。

## 从 0.1.0 升级

0.1.0 里还没有更新功能，这一次需要手动安装：下载 `DiskLens-0.2.0.zip`，解压后替换「应用程序」里的 DiskLens。之后的版本就可以在应用里直接更新了。

## 系统要求

macOS 14 Sonoma 及以上，Apple 芯片和 Intel 机型都能用。

## 安装

1. 下载 `DiskLens-0.2.0.zip`，解压后把 DiskLens 拖到「应用程序」文件夹。
2. 这个预览版还没有经过苹果公证，第一次打开时 macOS 会拦住。在「应用程序」里**按住 Control 点按 DiskLens，选「打开」**，再在弹出的提示里点「打开」。如果没有「打开」选项，到「系统设置 › 隐私与安全性」，在页面下方点「仍要打开」。
3. 首次启动时按引导开启「完全磁盘访问权限」，否则邮件、信息、废纸篓等位置扫描不到，结果会偏小。

## 隐私

所有分析都在本机完成，不上传文件名，不收集使用数据，也不需要账号。DiskLens 只会发出两种网络请求，都可以在设置里关闭：每天最多一次下载公开的清理规则，以及每天最多一次查看 GitHub 上的发布列表。删除的东西只会移到废纸篓。

## 已知问题

- 未经公证，首次打开需要按上面的步骤手动允许。
- 每次更新到新版本后，可能需要重新开启完全磁盘访问权限。

`DiskLens-0.2.0.zip.sig` 是安装包的签名，供应用内更新校验使用。
