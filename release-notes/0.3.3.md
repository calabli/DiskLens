DiskLens 0.3.3 预览版：看清系统数据里有什么。

## 新功能

- **按系统设置的分类看磁盘**：扫描整个磁盘后，「存储详情」会按开发者、文稿、应用程序、邮件、照片、iCloud 云盘、其他用户与共享、macOS、系统数据显示大小。macOS 没有公开这些分类的算法，所以这里是按文件夹估算的，数字接近系统设置，但不会完全相同。
- **系统数据里有什么**：列出动态壁纸、系统资源、缓存、临时文件、交换文件、系统数据库、日志等各占多少，并说明能不能清理。能清理的项目可以直接跳到清理建议。

## English

- After a whole-disk scan, Storage shows the same categories as System Settings: Developer, Documents, Applications, Mail, Photos, iCloud Drive, Other Users & Shared, macOS and System Data. macOS doesn't publish how it works these out, so the figures are estimates: close to System Settings, but not identical.
- A new list shows what's in System Data, such as aerial wallpapers, system assets, caches and temporary files, says what can be cleaned, and links to Suggestions for those that can.

## 升级

已经装了 0.2.x 或 0.3.x：在 DiskLens 菜单里选「检查更新…」，点「下载并安装」即可。

还在用 0.1.0：需要手动下载 `DiskLens-0.3.3.zip`，解压后替换「应用程序」里的 DiskLens。

## 系统要求

macOS 14 Sonoma 及以上，Apple 芯片和 Intel 机型都能用。

## 首次安装

1. 下载 `DiskLens-0.3.3.zip`，解压后把 DiskLens 拖到「应用程序」文件夹。
2. 这个预览版还没有经过苹果公证，第一次打开时 macOS 会拦住。在「应用程序」里**按住 Control 点按 DiskLens，选「打开」**，再在弹出的提示里点「打开」。
3. 首次启动时按引导开启「完全磁盘访问权限」。

## 已知问题

- 未经公证，首次打开需要手动允许。
- 每次更新到新版本后，可能需要重新开启完全磁盘访问权限。
- 「空间时间线」的增长来源按记录时的语言命名，切换语言前后的记录会混用两种语言。
- 存储分类是估算值。系统数据里各项相加，可能略大于系统数据的总量。
